Spoon へのコントリビューション
=============================

[English](CONTRIBUTING.md) | 日本語

1) Minecraft のクラスへのパッチは最小限にし、まとめて書いてください。多くの処理が必要な場合は、関係する Spoon/Forge のクラスに追加するか、新しいクラスを作ってください。離れた複数の行にパッチを散らすと、パッチの保守が難しくなるので避けてください。

2) Spoon にイベントやフックを追加するプルリクエストには、必ずサンプル Mod を付けてください。提案するフックを使った完全な Mod でも、簡単な例を貼った pastebin でもかまいません。新しいフックが何をするのかも詳しく説明してください。

3) 作業しているクラスのコードスタイルに合わせてください（Forge のクラスやパッチと同じく、波かっこは改行してから書き、インデントにはタブではなくスペースを使います）。

4) 既存の Forge Mod が動くようにしてください。`net.minecraftforge` / `cpw.mods.fml` パッケージや `Forge` / `FML` の Mod ID の名前は変えないでください。

ワークスペースの準備とパッチの作り直しについては、[README][Workspace] を参照してください。

Issue とプルリクエストは https://github.com/ukagaka-irono/MinecraftSpoon で受け付けています。
